# Лабораторная работа 1 — ML-конвейер

Простейший конвейер машинного обучения: генерация синтетических данных о дневной температуре, предобработка, обучение и оценка модели.

## Файлы

| Файл | Назначение |
|------|------------|
| `data_creation.py` | Генерирует синтетические CSV-наборы данных (чистые, зашумлённые, с аномалиями) и раскладывает их по папкам `train/` и `test/`. |
| `data_preprocessing.py` | Нормализует признаки с помощью `StandardScaler`. Скейлер подгоняется только на обучающей выборке. |
| `model_preparation.py` | Обучает случайный лес (RandomForest) на обучающих данных и сохраняет модель в `model.pkl`. |
| `model_testing.py` | Загружает сохранённую модель, оценивает accuracy на тестовых данных и печатает результат. |
| `pipeline.sh` | Bash-скрипт, запускающий все этапы по порядку. |

## Необходимые зависимости

- Python 3.8+
- pandas
- scikit-learn
- numpy

Установка:

```bash
pip install pandas scikit-learn numpy
```

## Запуск

```bash
cd lab1
bash pipeline.sh
```

В stdout будет выведена одна строка, например:

```
Model test accuracy is: 0.963
```

Промежуточные сообщения выводятся в stderr.

## Примечание

Данные генерируются синтетически с фиксированным `random_state`, поэтому результат воспроизводим и не требует подключения к интернету. Код написан с помощью AI-инструмента (Antigravity / Gemini).
